Caldence
========

English
-------
Caldence is a static web app. To host it:
1. Upload ALL files of this ZIP (including the hidden file .htaccess) to any
   folder of a web server. HTTPS is needed to install the app on a device.
2. Open that folder's address in your browser.

To try it locally, run "python3 -m http.server" in this folder and open
http://localhost:8000/ in your browser.

Details: https://github.com/gallandp/caldence/blob/main/docs/deployment.md

Deutsch
-------
Caldence ist eine statische Web-App. So stellen Sie sie bereit:
1. Laden Sie ALLE Dateien dieses ZIPs (auch die versteckte Datei .htaccess) in
   einen beliebigen Ordner eines Webservers hoch. Zum Installieren der App ist
   HTTPS nötig.
2. Öffnen Sie die Adresse dieses Ordners im Browser.

Lokal ausprobieren: "python3 -m http.server" in diesem Ordner ausführen und
http://localhost:8000/ im Browser öffnen.

Details (englisch): https://github.com/gallandp/caldence/blob/main/docs/deployment.md
